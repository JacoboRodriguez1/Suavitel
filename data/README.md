# Data

## Source

GoEmotions: a dataset of 58k Reddit comments labeled with 27 emotion categories plus neutral.

- Paper: Demszky, D., Movshovitz-Attias, D., Ko, J., Cowen, A., Nemade, G., & Ravi, S. (2020).
  *GoEmotions: A Dataset of Fine-Grained Emotions*. Proceedings of the 58th Annual Meeting of the
  Association for Computational Linguistics (ACL), 4040-4054.
- Kaggle: https://www.kaggle.com/datasets/debarshichanda/goemotions
- Original repository: https://github.com/google-research/google-research/tree/master/goemotions

This project uses the filtered version of the dataset (`train.tsv`, `dev.tsv`, `test.tsv`).

## Folders

- `raw/`: original dataset files. They are **not** uploaded to the repository; download them from the link above.
- `processed/`: balanced dataset and train/test splits produced by the project code.
