\section{Conclusions}
\label{sec:conclusions}

On the measured baseline and neural runs, Dense achieved the strongest test
macro F1, while the recurrent models retained token order but did not surpass
it on this small, balanced sample. All three neural models scored substantially
higher on training than test data, so the fit-to-test gap remains an important
part of the result. The five-model conclusion is pending the DistilBERT
fine-tuning and comparison outputs; we do not infer that Transformer is better
or worse without those measurements.

The architectures provide different computational trade-offs. Dense is a
compact, order-insensitive fixed-vector classifier; SimpleRNN and LSTM process
tokens sequentially with a bounded hidden state; DistilBERT relates tokens
through parallel self-attention over a bounded context. These mechanisms
illustrate memory and sequence processing, but their Turing-completeness
results rely on idealized assumptions and do not describe the practical
capacity of these finite, trained classifiers.

Future work should complete the three-seed DistilBERT run, report its train and
test scores beside inference latency and parameter counts on a stated device,
and select the overall model from that evidence. A larger independently
sampled test set, evaluation on another source of comments, and targeted tests
for negation, irony, and emoji would better measure generalization than more
initializations on the same 200 examples.
