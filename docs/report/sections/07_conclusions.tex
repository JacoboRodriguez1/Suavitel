\section{Conclusions}
\label{sec:conclusions}

Across the five measured models, DistilBERT achieved the strongest mean test
macro F1 (0.843), followed by Dense (0.741). Dense was the strongest of the
non-Transformer models, while SimpleRNN and LSTM retained token order but did
not surpass it on this small, balanced sample. The DistilBERT train/test gap
(0.093) was smaller than the Dense gap (0.249), although its inference time
was much longer on the measured CPU. Each neural model scored higher on
training than test data, so generalization remains a concern.

The architectures provide different computational trade-offs. Dense is a
compact, order-insensitive fixed-vector classifier; SimpleRNN and LSTM process
tokens sequentially with a bounded hidden state; DistilBERT relates tokens
through parallel self-attention over a bounded context. These mechanisms
illustrate memory and sequence processing, but their Turing-completeness
results rely on idealized assumptions and do not describe the practical
capacity of these finite, trained classifiers.

Next steps are a larger independent test set, a second comment source, and
GPU latency measurements. Targeted tests for negation, irony and emoji would
clarify failures; attention plots remain diagnostic rather than causal.
